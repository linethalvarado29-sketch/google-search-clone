# Google Search Clone

A functional front-end replication of Google's search interface, built as part of a technical web development challenge.

## Features
- **Core Search:** Functional main search bar using Google's GET parameters.
- **Image Search:** Dedicated page for Google Images queries.
- **Advanced Search:** Detailed filtering interface (All words, exact phrase, etc.).
- **Responsive Design:** Clean and minimalist UI that adapts to different screen sizes.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Custom Styling)
- Google Search Engine API (Query String Parameters)
